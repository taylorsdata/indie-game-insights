Game Data Analysis 📊🎮
Welcome to my Game Data Analysis repository! Here, I analyze a variety of indie games to uncover trends in player behavior, community sentiment, and gameplay metrics. This project is designed to compare different games based on their popularity, social media presence, player feedback, and other key factors.

🔍 What’s Analyzed:
Steam Reviews Sentiment: Analyzing player feedback and sentiments from Steam reviews.

Player Count Over Time: Tracking monthly active players to understand game trends and player engagement.

Social Media Trends: Analyzing mentions and hashtags across platforms like Reddit, TikTok, and Twitter to measure community engagement.

Twitch/YouTube Metrics: Monitoring streamer engagement and the game’s visibility on streaming platforms.

Most Popular In-Game Features: Identifying what features players love the most—whether it’s the greenhouse in Lemon Cake or the animal companions in Bear and Breakfast.

📁 Folder Structure:
data/: Raw & cleaned data files for each game (CSV, Excel)

visualizations/: Graphs, charts, and dashboards (from tools like Tableau or Excel)

reports/: Analysis reports and insights (PDFs or notebooks)

notebooks/: Jupyter or Colab notebooks used for analysis

🛠️ Tools & Technologies:
Excel: For data cleaning, tracking, and basic analysis

Python: For more complex analysis (using libraries like Pandas, Matplotlib, Seaborn)

Tableau: For data visualizations

Google Sheets: For easy collaboration and quick analysis
